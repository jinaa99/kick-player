# Kick тоглуулагч

Kick.com-ын шууд дамжуулалтыг MacBook дээр **1080p-ээр гацалтгүй** үзэх локал вэб апп.
Шууд эфирээс 10–45 секунд хоцорч, том буфертэй тоглуулна.

## Яагаад хэрэгтэй вэ

Монголоос гадаадын CDN хүртэлх нийт хурд хангалттай (~60–77 Мбит/с) ч, **нэг холболтын хурд**
өндөр, тогтворгүй ping-ээс болж хэт бага байдаг. Kick-ийн өөрийн тоглуулагч маш жижиг буфертэй тул
бага зэрэг саатахад л гацдаг.

Энэ апп хоёр зүйл хийнэ:

1. **Шууд эфирээс хойно сууна** — сонгосон хоцрогдлоор (20 сек гэх мэт) том буфер барина.
2. **Сегментүүдийг зэрэгцээ татна** — локал сервер playlist-ийг 2 секунд тутамд шалгаж, шинэ сегмент
   гармагц урьдчилан татна. Хэд хэдэн сегментийг зэрэг (анхдагч 4) татахаас гадна **сегмент бүрийг
   byte range-ээр 4 хэсэгт хувааж** зэрэг татна. Тоглуулагч сегментийг `localhost`-оос шууд авна.

Мөн Kick-ийн playlist зөвхөн ~28 секундийн цонхтой тул сервер сегментийн түүхийг (DVR, 150 сек хүртэл)
өөрөө хадгалж, урт playlist гаргадаг. Ингэснээр 30 болон 45 секундийн хоцрогдол боломжтой болно.

## Суулгах

### 1. Homebrew (байхгүй бол)

Terminal нээгээд:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Суулгасны дараа Terminal-ийн хэлсэн `eval "$(/opt/homebrew/bin/brew shellenv)"` мөрүүдийг ажиллуулна.

### 2. Node.js

```bash
brew install node
node -v   # v18 буюу түүнээс дээш байх ёстой
```

### 3. Аппыг суулгах

```bash
cd kick-player
npm install
```

Ганц хамаарал нь `hls.js` (тоглуулагчийн сан).

## Ажиллуулах

```bash
npm start
```

Дараа нь Chrome эсвэл Safari дээр **http://localhost:8080** нээнэ.
Сувгийн нэр (жишээ нь `xqc`) эсвэл `kick.com/…` холбоосыг оруулаад **Үзэх** дарна.

Зогсоохдоо Terminal дээр `Ctrl+C`.

### Mac асахад автоматаар ажиллуулах (зөвлөмж)

Нэг удаа ажиллуулахад л хангалттай:

```bash
npm run autostart
```

Үүний дараа сервер Mac асах бүрт ард ажиллаж эхэлнэ. Terminal нээх шаардлагагүй, хөтөч дээрээ
**http://localhost:8080**-ыг bookmark хийгээд нээхэд л болно. Унтарвал өөрөө дахин асна.

| Команд | Үйлдэл |
|---|---|
| `npm run restart` | Код шинэчилсний дараа серверийг дахин эхлүүлэх |
| `npm run autostart:off` | Автоматаар асахыг болиулах |

Лог: `~/Library/Logs/kick-player.log`. Автомат горимд байхад `npm start`-ийг тусад нь бүү ажиллуулаарай
(хоёулаа 8080 портыг эзлэх гэж өрсөлдөнө).

### Яагаад Vercel гэх мэт сервер дээр байршуулж болохгүй вэ

Гацалтыг засаж байгаа зүйл нь таны компьютер Kick-ийн CDN-ээс **олон шинэ холболтоор зэрэг** татах
явдал. Сервер гадаадад байвал видео тэндээс таны хөтөч рүү дахиад нэг холболтоор, ачаалалтай гадаад
замаар ирэх тул гацалт буцаж гарна. Мөн Vercel-ийн serverless функц кэш/DVR хадгалж чаддаггүй,
урсгалын хязгаартай (1080p60 цагт ~4 ГБ), Kick-ийн Cloudflare датацентрийн IP-г ихэвчлэн хаадаг.

## Ашиглах

| Тохиргоо (⚙ цэс) | Тайлбар |
|---|---|
| **Хоцрогдол** | 5 / 10 / 20 / 30 / 45 сек. Их байх тусам гацах магадлал бага. 10 сек ба түүнээс бага үед сервер playlist-ийг секунд тутам шалгаж, одоо кодлогдож буй сегментийг урьдчилан татна. Хэмжилтээр: 20 сек — гацалтгүй, 10 сек — хааяа, 5 сек — минутад хэд хэдэн удаа (сүлжээний хэлбэлзлийг шингээх буфер хэтэрхий бага). |
| **Чанар** | Анхдагч нь хамгийн өндөр (1080p). «Автомат» нь сүлжээнээс хамаарч чанараа сольдог. |
| **Горим** | **Прокси** — зэрэгцээ татах (зөвлөмж). **Шууд** — нэг холболт, урьдчилан татахгүй; харьцуулахад зориулсан. |
| **Зэрэгцээ** | Хэдэн сегментийг зэрэг татах вэ (2–8). |
| **Чат** | Kick-ийн чатыг баруун талд харуулна. Оруулах боломжгүй бол «Шинэ цонхонд» холбоос гарна. |

### Дуртай сувгууд

Зүүн талын жагсаалтад дуртай сувгуудаа хадгална. Эфирт байгаа нь дээрээ, үзэгчийн тоотойгоо гарна
(минут тутамд шинэчлэгдэнэ). Нэг дээр нь дарахад шууд тоглоно.

- Суваг үзэж байхдаа хайлтын хажуугийн **☆** товчийг дарж нэмнэ, эсвэл «+ Суваг нэмэх» талбарт бичнэ.
- **Импорт** — Kick-ийн follow-уудаа нэг дор оруулах. Kick-д үүнд зориулсан албан ёсны API байхгүй тул
  kick.com-ын `session_token` cookie-г нэг удаа буулгана (заавар нь цонхон дотор байгаа). Токен
  хаана ч хадгалагдахгүй, зөвхөн сувгийн нэрс жагсаалтад нэмэгдэнэ. Энэ нь Kick-ийн албан бус
  endpoint тул хэзээ нэгэн цагт ажиллахаа больж магадгүй. Тэгсэн ч гараар нэмсэн жагсаалт хэвээр ажиллана.

### Чат

- **Чат** таб — апп дотор чатыг уншина: emote, subscriber болон level badge харагдана.
  **Видеотой тааруулах** асаалттай үед мессеж видеоны хоцрогдлоор хойшилж гарна (спойлергүй).
- **Чатад бичих** — чатын доорх талбараас шууд бичнэ. Emote-ийг ☺ товчоор сонгох, дээрх мөрнөөс дарах,
  эсвэл нэрийг нь бичихэд (жишээ нь `KEKW`) автоматаар emote болно. Дээрх мөр болон «Байнга ашигладаг» таб
  таны хамгийн их ашигладаг emote-уудыг харуулна (энэ хөтөч дээр хадгалагдана). ⚙ — «Видеотой тааруулах», гарах.
  Kick-ийн «Collectibles» emote, channel points, KICKs үлдэгдэл нийтийн API-д байхгүй тул харагдахгүй. Таны мессеж Kick дээр шууд (хоцрогдолгүй) гарна,
  апп дотор ч шууд харагдана.
- **Kick** таб — kick.com-ын өөрийн чат (Chrome дээр kick.com-д нэвтэрсэн бол). **Цонхонд ↗** — тусдаа цонхонд.

#### Чатад бичих тохиргоо (нэг удаа)

Kick гадны апп-аас бичихийг зөвхөн албан ёсны API-аар зөвшөөрдөг тул өөрийн "Kick app" үүсгэнэ.
«Kick-ээр нэвтэрч бичих» товчийг дарахад алхам бүрийн заавар гарна:

1. kick.com → Settings → Security дээр 2FA асаах.
2. [kick.com/settings/developer](https://kick.com/settings/developer) → Create App.
   Redirect URL: `http://localhost:8080/auth/callback`, scope: `user:read`, `chat:write`.
3. Client ID, Client Secret-ийг апп-д буулгаад нэвтэрнэ (жижиг popup цонх, видео тасрахгүй).

Client ID/Secret болон токен зөвхөн `~/.kick-player/config.json`-д (зөвхөн таны уншиж чадах эрхтэй)
хадгалагдана. Сервер өөр вэб сайтаас ирсэн хүсэлтийг хүлээж авахгүй тул таны нэрээр өөр хэн ч бичиж чадахгүй.

Энэ апп-аар үзсэн цаг Kick-ийн watch-time XP/level-д **тооцогдохгүй**. Үүнийг дуурайвал Kick
view-bot гэж үзэж аккаунтыг хаах эрсдэлтэй тул санаатайгаар хийгээгүй.

**Товчлуурууд** (монгол гарын байрлалд ч ажиллана):

| Товч | Үйлдэл |
|---|---|
| `T` | Театрын горим — видео дэлгэц дүүргэж, чат баруун талд (`Esc` гарна) |
| `F` | Бүтэн дэлгэц |
| `Space` | Тоглуулах / зогсоох |
| `M` | Дуу хаах / нээх |
| `C` | Чат харуулах / нуух |

Видеон доорх удирдлага: тоглуулах, дуу (дээр нь очиход гулсуур гарна), эфирийн хугацаа, LIVE ба
хоцрогдол, чат, театр, зураг доторх зураг, бүтэн дэлгэц, ⚙ тохиргоо (хоцрогдол, чанар, горим, зэрэгцээ).
Дээд талын ногоон зурвас нь урагшаа буферийг харуулна (улаан = 3 секундээс бага).

Сүүлд үзсэн сувгууд дээд хэсэгт хадгалагдана. `http://localhost:8080/#xqc` гэж шууд нээж болно.

### Үзүүлэлтүүд

- **Буфер** — урагшаа хэдэн секунд бэлэн байгаа. Шар = хэвийн, улаан = 3 секундээс бага.
- **Эфирээс хоцрогдол**, **Гацалт**, **Хурдны тооцоо** — тоглуулагчийн үзүүлэлт.
- **Кэш онох / хүлээсэн / алдсан** — тоглуулагч сегментийг кэшээс авсан / татагдаж байхад нь хүлээсэн / шинээр татсан тоо.
- **Дундаж сегмент** — upstream-ээс нэг сегмент татахад зарцуулсан хугацаа. 2 секундийн сегментэд
  2 секундээс их байвал нэг холболтоор гацах байсан гэсэн үг — зэрэгцээ татах нь үүнийг нөхдөг.

### Зөвлөмж

- **Идэвхтэй татан авалтын «дараалал»** байнга өсөөд байвал **Зэрэгцээ**-г 6 эсвэл 8 болго.
- «Автомат» чанар заримдаа 720p руу бууж магадгүй (сегмент шинээр гарахыг хүлээх хугацааг
  удаан сүлжээ гэж тооцдог). 1080p хүсвэл «Хамгийн өндөр»-ийг сонго.
- Холбоосны хугацаа дуусвал (токен) сервер болон тоглуулагч хоёулаа автоматаар шинэ холбоос авч үргэлжилнэ.

## Суваг хэрхэн олдог вэ

`/api/resolve?channel=NAME` дараах дарааллаар оролдоно:

1. **Kick API** (`kick.com/api/v2/channels/NAME`) — Node-оос. Cloudflare ихэвчлэн 403 өгдөг.
2. **Kick API (curl)** — macOS-ийн `curl`-ээр ижил хүсэлт. Cloudflare үүнийг ихэвчлэн нэвтрүүлдэг.
3. **streamlink** — суулгасан бол.
4. Бүгд амжилтгүй бол **гараар оруулах** цонх гарна.

### streamlink суулгах (заавал биш, нөөц арга)

```bash
brew install streamlink
streamlink --version
```

### Гараар оруулах

Автоматаар олдохгүй бол «Гараар оруулах» цонхонд:

1. `https://kick.com/api/v2/channels/NAME` хуудсыг хөтөч дээрээ нээнэ.
2. Бүх текстийг хуулна (`⌘A`, `⌘C`) — эсвэл зөвхөн `.m3u8` холбоосыг.
3. Буулгаад «Ачаалах» дарна.

JSON буулгасан бол сувгийн нэр мэдэгдэх тул токен дуусахад автоматаар шинэчилнэ.
Зөвхөн URL буулгасан бол хугацаа нь дуусахад дахин буулгах хэрэгтэй.

## Нэмэлт тохиргоо (орчны хувьсагч)

```bash
PREFETCH_CONCURRENCY=6 CACHE_MB=500 npm start
```

| Хувьсагч | Анхдагч | Тайлбар |
|---|---|---|
| `PORT` | 8080 | Серверийн порт |
| `PREFETCH_CONCURRENCY` | 4 | Зэрэгцээ татах тоо (UI-аас ч сольж болно) |
| `CACHE_MB` | 300 | Сегментийн кэшийн дээд хэмжээ (МБ) |
| `DVR_SECONDS` | 150 | Сервер хэдэн секундийн түүх хадгалах |
| `PREFETCH_WINDOW` | 60 | Playlist-ийн сүүлийн хэдэн секундийг урьдчилан татах |
| `SEGMENT_PARTS` | 4 | Нэг сегментийг хэдэн холболтоор хэсэгчлэн татах (`1` бол хуваахгүй) |
| `CHUNK_KB` | 1024 | Нэг хэсгийн хэмжээ (КБ) |
| `POLL_MS` | 2000 | Сервер upstream playlist-ийг хэр олон шалгах (мс) |
| `LOG_SEGMENTS` | 1 | `0` бол сегмент бүрийн логийг унтраана |
| `ALLOWED_HOSTS` | live-video.net,kick.com,… | Прокси зөвхөн эдгээр хост руу хандана |

Сервер зөвхөн `127.0.0.1` дээр сонсдог тул сүлжээний бусад төхөөрөмжөөс хандах боломжгүй.

## API

| Зам | Тайлбар |
|---|---|
| `GET /api/resolve?channel=NAME` | `{ url, live, method, attempts }` |
| `POST /api/manual` | Их бие нь m3u8 URL эсвэл API JSON → `{ url, live, method, channel }` |
| `GET /api/channels?slugs=a,b` | Сувгуудын эфирийн төлөв, үзэгч, avatar, чатын ID |
| `GET /api/chat/history?channelId=ID` | Сүүлийн чатын мессежүүд |
| `POST /api/follows/import` | `{ "token": "…" }` → `{ slugs }` (токен хадгалагдахгүй) |
| `GET /api/stats` | Кэш, татан авалтын хурд, идэвхтэй татан авалт, DVR |
| `POST /api/config` | `{ "concurrency": 6 }` |
| `GET /api/emotes?slug=NAME` | Сувгийн, Global, Emoji emote-ууд |
| `GET /api/auth/status`, `POST /api/auth/config`, `POST /api/auth/logout` | Kick нэвтрэлт |
| `GET /auth/login`, `GET /auth/callback` | OAuth (PKCE) урсгал |
| `POST /api/chat/send` | `{ broadcasterUserId, content }` — албан ёсны Kick API-аар илгээнэ |

POST хүсэлтүүд `x-kick-player: 1` header шаарддаг (өөр сайтаас хүсэлт илгээхээс хамгаална).
| `GET /proxy/master.m3u8?c=NAME&u=URL` | Дахин бичсэн master playlist |
| `GET /proxy/media.m3u8?…` | DVR-тэй media playlist (урьдчилан татахыг эхлүүлнэ) |
| `GET /proxy/seg?u=URL` | Сегмент (кэш → татагдаж буйг хүлээх → шинээр татах) |

```
lib/proxy.mjs       Playlist дахин бичих, LRU кэш, зэрэгцээ prefetch, DVR, токен шинэчлэх
public/             Нэг хуудастай frontend (hls.js)
```
