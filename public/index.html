    Kick-ийн follow-уудыг импортлох

    Kick-д follow жагсаалт авах албан ёсны API байхгүй тул таны нэвтрэлтийн токеныг нэг удаа ашиглана. Токен хаана ч хадгалагдахгүй, зөвхөн сувгийн нэрс таны дуртай жагсаалтад нэмэгдэнэ.

    1. kick.com-д нэвтэрсэн Chrome дээр ⌥⌘I дарж DevTools нээнэ.
    2. Application → Cookies → https://kick.com → session_token мөрийн Value-г хуулна.
      (Safari: Develop → Show Web Inspector → Storage → Cookies)
    3. Доор буулгаад «Импортлох» дарна.

    ⚠ Энэ токен таны аккаунтын түлхүүр. Өөр хэнд ч, өөр сайтад ч бүү өгөөрэй.

    Чатад бичих тохиргоо (нэг удаа)

    Kick нь гадны апп-аас чатад бичихийг зөвхөн албан ёсны API-аар зөвшөөрдөг. Үүний тулд өөрийн Kick аккаунт дээр жижиг "app" үүсгэнэ — 3 минут орчим.

    1. kick.com → Settings → Security хэсэгт 2FA асаасан байх шаардлагатай.
    2. kick.com/settings/developer → Create App.
    3. Нэр: дурын (жишээ нь "Kick тоглуулагч").
      Redirect URL:
    4. Scope-оос user:read (Read user information) болон chat:write (Write to Chat)-ийг сонгоно.
    5. Гарч ирсэн Client ID, Client Secret-ийг доор буулгана.

    Эдгээр нь зөвхөн таны компьютер дээр (~/.kick-player/) хадгалагдана.
