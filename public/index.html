    Kick-ийн follow-уудыг импортлох

    Kick-д follow жагсаалт авах албан ёсны API байхгүй тул таны нэвтрэлтийн токеныг нэг удаа ашиглана. Токен хаана ч хадгалагдахгүй, зөвхөн сувгийн нэрс таны дуртай жагсаалтад нэмэгдэнэ.

    1. kick.com-д нэвтэрсэн Chrome дээр ⌥⌘I дарж DevTools нээнэ.
    2. Application → Cookies → https://kick.com → session_token мөрийн Value-г хуулна.
      (Safari: Develop → Show Web Inspector → Storage → Cookies)
    3. Доор буулгаад «Импортлох» дарна.

    ⚠ Энэ токен таны аккаунтын түлхүүр. Өөр хэнд ч, өөр сайтад ч бүү өгөөрэй.
